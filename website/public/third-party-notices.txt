tensor.cx website: third-party notices
=====================================

These notices accompany third-party code and styles delivered with the static
website, including its search assets. They do not change the upstream licenses
or the Apache-2.0 license of tensor.cx's own source. Native runtime notices are
maintained separately in the repository's THIRD_PARTY_NOTICES.md.

This is not a list of every dependency used by the build tools. Installed
package versions below identify the source used for this notice review.
Pagefind also supplies prebuilt browser bundles; their embedded dependency
patch versions are not all exposed by the published package. Update these
notices when changing the dependencies or browser assets.
