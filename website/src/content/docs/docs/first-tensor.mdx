## What happens

`best_device()` selects an available accelerator, falling back to CPU. Each
`ones` call allocates a contiguous tensor on that device. Addition executes
synchronously and returns a new tensor. `.cpu().numpy()` copies the result to
the CPU as needed and returns a NumPy array.

For a reproducible CPU baseline, change `device = cx.best_device()` to
`device = "cpu"`. Constructors without a `device` argument also default to CPU.

## Device selection is explicit

Use `cx.devices()` to list available devices and `cx.is_available("cuda")`,
`cx.is_available("metal")` or `cx.is_available("vulkan")` before selecting an
accelerator. Use `tensor.to("cuda")`, `tensor.to("metal")` or
`tensor.to("vulkan")` to transfer a tensor explicitly.

CPU, Metal and CUDA currently expose index 0. Vulkan accepts indexed routes
such as `vulkan:0`; only one physical Vulkan GPU has been validated. See the
[device support matrix](/docs/backends/) and [optional Vulkan setup](/docs/vulkan/).

Binary operations accept broadcast-compatible shapes with matching dtypes and
devices. Use `astype` to convert dtype explicitly; operations never move inputs
between devices. Read [tensor operations](/docs/operations/)
for the next steps.
